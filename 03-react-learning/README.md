# React Learning

A hands-on React learning project created to practice and understand React fundamentals through real examples and mini-features.

## Topics Covered

### React Basics

* Functional Components
* JSX
* Props
* Default Props / Default Parameters
* Conditional Rendering
* Handling Missing Data
* Dynamic Rendering with `map()`
* React Keys

### State Management

* useState Hook
* Updating State
* State-driven UI Updates
* Toggle Functionality

### Event Handling

* Button Click Events
* Form Input Handling
* Methods as Props

### Side Effects

* useEffect Hook
* Component Mounting
* Dependency Arrays
* Cleanup Functions
* Browser Title Updates

### Practical Features Implemented

* Student Records Display
* User Search Functionality
* Product Search Functionality
* Product Sorting by Price
* Product Filtering
* Loading States
* Theme Toggle (Light/Dark)
* Digital Clock
* API Data Fetching

### API Integration

* Fetch API
* Async/Await
* Error Handling
* Loading Indicators

### Data Operations

* Array Mapping
* Sorting
* Filtering
* Searching
* Conditional UI Rendering

## Getting Started

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Start development server

```bash
npm run dev
```

## Learning Goals

This project was built to understand:

* How React components work
* How data flows through props
* How state management works using useState
* How side effects work using useEffect
* How to fetch and display API data
* How to sort, filter, and search dynamic data
* How React re-renders UI based on state changes
